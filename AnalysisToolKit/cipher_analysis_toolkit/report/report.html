Interpretation checklist

  • If every file length is divisible by 16, treat the data as block-aligned ciphertext.
  • If there are no repeated 16-byte blocks, ECB is not proven and simple repeated-block leakage is not visible.
  • Pairwise Hamming distances near 50% suggest strong diffusion or unrelated keys/IVs.
  • No obvious PKCS#7 padding does not eliminate AES/CBC/ECB, but it means the final byte pattern does not reveal padding directly.
  • The next practical step is to test candidate algorithms/modes with any key/password hints, not to brute-force random AES keys.
